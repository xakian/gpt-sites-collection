# 半導體製程實驗基地

全新、獨立的 Sites 單機遊戲。已完成 HexBase v0.4 的首次底層整理與可操作示例；目前唯一取得的 Word 是《半導體科學遊戲_底層沿用與開發交接規格_v1.docx》，尚未取得正式遊戲內容 Word，不能把本版示例視為正式內容已完成。

原始碼 ZIP 未出現在指定下載區。改由交接文件提供的來源 Site 讀取原始碼，取得的 v38 提交 `edd19a5426da16b766de618faf48bd4b65208b32` 與文件完全相同。原站、聯機房間、部署身分與資料未修改；新站使用自己的來源倉庫、Site 身分與本機存檔命名空間。

## 操作

點「開始運轉」，在物料庫右側入口取 1 片試驗晶圓。選取製程示意站 → 前往入口 → 放料 → 啟動 → 等待 → 取出；再到檢測站重複操作；到交付站放料並提交。首次交付解鎖人員，建議一名搬運、一名操作；玩家離開入口讓工人通行。

E / I / J / N / C / D 是六向單次移動，空白為目前情境互動。可點地面尋路，拖曳平移，滾輪或按鈕縮放，恢復跟隨玩家。設備清單可用鍵盤選取。建造先預覽，確認才扣費；Esc 或取消不扣費。

「存檔」提供手動保存、自動存檔讀取及 JSON 匯出／匯入。儲存只在目前瀏覽器，新站與原遊戲隔離；沒有離線收益。載入後保持暫停，確認後自行繼續運轉。

## 本機執行與檢查

此站是原生 JavaScript、CSS、Canvas，沒有套件依賴或編譯步驟，Node.js 24 即可執行。

```text
node serve.mjs
node --test tests/game.test.mjs
node scripts/validate.mjs
```

本機預覽為 `http://127.0.0.1:4317`。也提供 `npm run dev`、`npm test`、`npm run validate`、`npm run build`；build 對此靜態專案執行相同發布前驗證。僅將 `dist/` 部署為網站，`docs/`、測試、來源紀錄不包含在網頁資產中。
