# PVD 金屬濺鍍 1.0.0

第二批02。共用規格v1.0、範本1.0.0。`node server.mjs` 後開啟 http://127.0.0.1:4202 。無第三方執行依賴。

30秒非反應式DC鋁靶／Ar濺鍍。固定腔體、平坦晶圓。Ar⁺與Al分離，鋁附著晶圓或擋板；停機保留薄膜。靶耗損小於幾何解析度，不每輪換靶。成品與新晶圓分開進出。

`dist/model.js` 是階段、純科學狀態及面板來源；`drawing.js` 處理SVG與布局；`svg.js` 保存材料色／圖形函式；`app.js` 接上原樣共用播放器。關鍵幀2、5.5、8.2、10.1、18、24、27、29秒。

私人Site識別見 `.openai/hosting.json`，發佈證據與未測項目見 `../../records/pvd-sputtering/`。
