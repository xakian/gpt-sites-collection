# 散熱蓋與 TIM 組裝

中央傳熱，周邊固定

從已安裝晶粒的封裝開始。中央TIM1採矽膠導熱膏型代表，依Dow TC-5026的non-curing屬性；中央材料不做固化轉變。周邊膠採DOWSIL 3-6265類熱固化矽膠代表，固化的是周邊固定膠。兩種材料組合僅為教學模型，不宣稱已驗證的配方或組裝條件。

TIM填補晶粒頂面與蓋內表面間的微小空隙，降低接觸熱阻。短暫A放大圖將表面粗糙大幅放大；主圖的層厚亦不按比例。TIM沒有熔成焊料，顏色全程一致。

周邊蓋膠只在基板邊緣承接金屬蓋邊，與中央TIM分開。蓋下降後控制中央與周邊層厚，兩者不跨越晶粒側邊的保持淨空區。材料色用於辨識，並非商品實際顏色。

橙色箭頭代表定性熱傳路徑，熱由晶粒經TIM1進入金屬蓋，再穿過外部散熱邊界。邊界代表後續TIM2及散熱系統的總作用，不是蓋本身消滅熱量；本輪不裝散熱器、不求解溫度或流體。不同TIM配方的電性不一概而論。

## 關鍵幀與腳本

3秒 已裝晶粒與新蓋：晶粒已裝在基板上；觀察晶粒頂面與蓋內表面的微小空隙。 A為粗糙度示意，尺寸大幅放大。此輪不重作固晶或底填。

9秒 中央TIM與周邊膠：中央晶粒頂面施加TIM，基板兩側蓋邊位置施加固定膠。 兩種顏色對應不同用途，中間保持淨空。

15.5秒 對準下降與接觸：金屬蓋下降，中央TIM展開填入間隙，蓋邊落在周邊膠上。 控制兩處層厚，材料不穿透晶粒、不流入側邊淨空區。

20秒 蓋膠固化與層厚穩定：周邊膠受熱固化，TIM維持受控的薄層接觸。 本例TIM是不固化導熱膏；不能把周邊膠的固化套用到它。

24秒 熱交給外部散熱：橙色熱流從晶粒經TIM到金屬蓋，繼續越過外部散熱邊界。 材料色與熱流分開；不顯示無依據的溫降或效率。

26.3秒 完成件移交：組裝件完整退場，下一輪由新封裝與新蓋開始。 固化膠不被吸回工具，TIM不倒流成施膠前狀態。
