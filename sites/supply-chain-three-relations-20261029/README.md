內建瀏覽器桌面／手機整輪、十一關鍵幀、控制及五種尺寸首屏通過。連續指標拖曳、真實背景返回、系統減少動態及實體手機尚未實測；原因與完整證據見交付驗收紀錄。本機強制減少動態與單元測試不代表系統實測。以下歷史記錄以原版本測試為準。

## 觀看與啟動

- 本機 HTTP 預覽：需要 Node.js 20 或更新版本，在本專案目錄執行 `node server.cjs`，開啟 http://127.0.0.1:4173 。不需要安裝套件。共用程式使用模組，請經 HTTP 預覽。
- 停止預覽：在啟動它的終端機按 Ctrl+C。
- 網站為純靜態檔，`dist/` 可放到其他靜態網頁主機。無編譯步驟、無依賴，故不需要套件鎖定檔。
- Sites 網址：https://supply-chain-three-relations-20261029.fishddry.chatgpt.site 。預設為擁有者私人網站，使用建立本網站的 ChatGPT 帳戶存取。部署結果以交付時的網站回應為準；本機副本可離線觀看。

## 操作

一般情況開啟即播放；可暫停、接續、重播、切換 0.5／1／1.5／2 倍速及拖動時間軸。開說明會暫停，關閉仍暫停；「播放接續」收合面板並接續。說明內可選十一階段並「定位此步」，另有理解檢查、案例限制與四個來源。拉桿可用 Home／End 定位首尾，方向鍵微調。系統減少動態初始停在 29 秒總覽，第一次明確播放從頭開始。

頂列右側依序為播放／暫停、重播、說明圖示，均可用鍵盤操作。2026-10-30 依使用者要求將頁首標題縮至桌面 12px、手機 11px，降低字重；三種關係圖例移入說明面板。控制圖示縮為 18px，保留 44px 點按範圍。階段文字、時間、速度與拉桿在底部。原頁首的「半導體・關係觀察 01」及兩句總結也保留在說明面板。一般觀看時整頁依視窗高度配置，說明面板可獨立捲動。

同日再依使用者要求壓縮上下間距，移除 600／620px 最低頁高，改用 100dvh 配置，讓拉桿留在首屏。底部步驟標題縮至桌面 13px／手機 12px；手機將步驟與時間速度並排，保留拉桿及控制的 44px 操作高度。1280×500、1024×768、390×844、360×560、844×390 各三個較長文案狀態均確認頁面無垂直溢出、拉桿完整可見。

## 續作位置

| `dist/index.html` | 主題入口、說明、來源及控制介面 |

| `tests/restyle.cjs` | 1.1.0 的多尺寸一屏、內容保留、控制與完整播放回歸 |

| `供應鏈_物料服務資訊_動畫任務_v1.txt` | 使用者提供的原始任務檔，完整保留 |

渲染採 Inline SVG，只有一個實物批次節點；文件節點預先建立、依時間顯隱，不逐輪新增。`window.SCPlayer.state()` 可讀時間、模型、布局、輪數與節點數；`destroy()` 暫停、取消 RAF 並移除控制監聽。`pagehide` 取消 RAF，`pageshow` 重建時間基準後依原意圖續播。

播放與布局功能屬此獨立專案，尚未抽成其他主題可共用的套件。網站版本由 `package.json` 記錄；`model.js` 的狀態模型版本仍為 1.0.0，本輪完全未改。有 Git 時可用 `git rev-parse HEAD` 取得本份來源 commit。

## 檢查

`node tests/model.test.cjs`（亦可 `npm test`）。

選用瀏覽器驗收：安裝 Playwright 或設定 `PLAYWRIGHT_MODULE` 為已有模組路徑；必要時設定 `QA_BROWSER` 為 Chromium／Edge 執行檔路徑。先啟動網站，再執行 `node tests/browser.cjs`。預設輸出在已忽略的 `qa-local/`；`QA_OUTPUT` 可變更輸出位置。瀏覽器測試工具不是網站執行依賴。

本輪美術回歸執行 `node tests/restyle.cjs`，使用相同環境變數設定。證據存於 `evidence/v1.1/`。測試已覆蓋 1440×900、1366×768、1280×720、390×844、375×667、360×740 的一屏觀看。極矮視窗保留最低可讀高度，可能需垂直捲動。

已知驗證限制：真實背景分頁 30 秒切回未測；實體手機、其他瀏覽器及學習成效未測。沒有已知尚待修復的核心內容或操作故障。
