# 封裝微流道單相液冷

批次06／8；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4608/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

參考IBM單晶片模組的單相矽微流道冷卻器，選用銀填充環氧（Ag epoxy）接合於晶片背面。主圖用一條代表流道的縱剖面呈現晶片→接合層→矽壁→流體的連續熱路；外部泵與換熱器是概念迴路改編，未重現論文的管路尺寸。裝置已充液且持續循環；金框短段只是同一小段流體的追蹤標記，不是氣泡或固體顆粒。色溫、速度、流道厚度與熱箭頭均為定性示意，不求解壓降、湍流或三維流場，也不引用為性能量測。
