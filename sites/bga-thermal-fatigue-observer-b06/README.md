# BGA 焊點熱循環疲勞

批次06／6；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4606/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

選用SAC305板級BGA代表剖面。上封裝與下電路板以共同中心對稱伸縮；本例電路板的有效膨脹較大，外側焊點受較明顯相對位移。形變、裂紋及循環時間放大，只用室溫／熱端／冷端示意，所有溫度低於焊料熔點，不提供壽命或循環數預測。封裝側裂紋參考UMD研究案例，不宣稱所有封裝都在相同位置失效。放大窗是右側同一焊點的同步資訊副本。

驗收證據：../../records/bga-thermal-fatigue/ 。站點身分只使用 .openai/hosting.json，禁止再次註冊。正式版本與私人網址以 ../../records/batch-06/progress.json 為準。
