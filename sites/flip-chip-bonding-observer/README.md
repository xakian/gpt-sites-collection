# 倒裝接合——晶粒翻過來，怎麼接到基板？

主題網站 **1.0.0**，共用規格 **v1.0**，共用程式範本 **1.0.0**。私人 Sites 專案識別保存在 `.openai/hosting.json`；不得複製此識別建立其他主題。

36 秒、八階段，追蹤一顆晶粒、A–D 四個代表焊料凸塊與封裝基板。使用「超低殘留免清洗助焊＋迴焊接合＋毛細底填＋加熱固化」示例。無第三方執行依賴、後端或外部字型。

## 本機執行

需要 Node.js 20 或更新版本。在本資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:4183 。埠已與其他主題區隔；若占用，請換本主題的埠，不停止其他服務。直接以檔案網址開啟不支援 ES modules，請使用 HTTP。

執行必要邏輯檢查：`node --test tests/*.test.js`。本次 Node v24.22.1，11 項通過。npm 在本次 PATH 不可用，直接用 Node 執行即可，不必安裝套件。

## 原始碼

- `dist/shared/`：未改動的 canonical 範本 1.0.0 副本及版本雜湊。
- `dist/model.js`：科學階段、時間狀態、接點及焊點幾何。
- `dist/app.js`：SVG 材料、投影、響應式布局與共用播放器接合。
- `dist/topic.css`：主題標示與補充圖樣式。
- `dist/index.html`：繁體中文說明、俯視補充圖、必要簡化與原廠來源。
- `tests/`：接點連續性、不可逆材料順序、邊界與時鐘行為。

## 操作

一般開啟即播放；右上角播放／暫停、重播、說明。底部可選 0.5／1／1.5／2 倍速；貼底拉桿可點選及拖曳，定位後保持暫停。說明可獨立捲動，選步不跳動畫，按「定位此步」才定位。

鍵盤 Tab、Enter／空白鍵操作控制，畫布空白鍵播放／暫停，拉桿支援方向鍵、Home、End。系統減少動態初始停於 31.5 秒完成態，明確播放從頭開始。
