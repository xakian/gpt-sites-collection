此專案依使用者 2026-10-29 上傳的《半導體知識座標圖 Work 建站提示詞》實作。第一版包含 48 個主題、72 筆已確認具名關係與 27 項原始／官方來源。採 buildless HTML、CSS、ES modules、SVG，不需要套件安裝或建置。

## 模型定義

P 與 M 是 0–4 離散、可修訂的編輯評分，分別衡量原理與實作在已界定單元範圍中的側重。0 沒有直接討論、1 背景提及、2 次要內容、3 主要目標、4 核心主旨。兩者獨立，不需相加為定值，不代表客觀知識量、重要性或難度。任何調整需更新理由與 updatedAt。

S 只計 confirmed「收錄於」直接入邊的不同子題 ID；R 計 confirmed 直接相連的不同其他主題 ID，入出合併去重。計算使用完整資料，不受搜尋、類型、視圖與縮放影響。排除自我、無效端點及 pending 關係。收錄於為編輯組織決策，已在關係依據中標示，不等同是一種。

評分狀態為 known、unknown、pending、not_applicable。只有 known 且是合法非負整數（P、M 不大於 4）才可定位；其他狀態的 value 必須 null。任一軸不成立就整點進外圍，不能以 0 代缺值。P、M 固定 0–4；S、R 使用完整資料上限，全部為 0 時只把顯示範圍設為 0–1 以避免退化。

## 顯示決策

每個主題各自顯示為半徑至多 2.6 px 的小點（極窄密集畫面依最近點距縮小），不再合併同座標主題或顯示成員數字。相同數值的主題在原座標附近固定錯位；偏移限制在每軸 0.38 個刻度且最多 70 px，邊界向內分布，並不改寫評分。移入與詳情顯示真實數值。布局按完整資料與穩定 ID 計算，搜尋及選取不改變點位。點按取 20 px 範圍內最近的一個主題，鍵盤仍可逐點操作。名稱預設開啟並自動避讓，放不下的名稱可移入／點按查閱，主題本身不會因此移除。

畫布固定適應視窗，移除圖內滾輪縮放、雙指縮放、拖曳平移及縮放控制；保留瀏覽器本身的頁面縮放。開關設定、詳情、收錄樹與圖例仍用覆蓋浮層，不改變圖面大小。搜尋與類型條件淡化未符合主題，保留完整位置；結果清單仍只列符合條件的主題。未定位主題以空心點呈現，缺值不當成零，位置不承載第三維。

關係視角固定雙圖：寬度至少 680 px 時左 58% 為局部直接關係、右 42% 為完整地圖；窄螢幕上下同時顯示。左圖保留每筆具名、有向關係、箭頭樣式、條件與來源；右圖每個主題只有一個點，同一對主題的多種方向與關係僅在視覺上合為一條無向淡線，沒有修改原資料。內建 48 主題、72 關係在右圖形成 68 條簡化連線。右圖布局以完整資料確定性計算，每次換主題只改高亮，中心主題圈選、直接鄰居次亮；左右均可切換中心，再點目前主題或右上角資訊鈕開詳情。沒有連線的主題仍顯示獨立點。收錄路徑與層數仍由已確認「收錄於」決定，網路幾何不解讀為層級或數值。


localStorage v3 保存所選視角、軸、面板、主題、定位樹／圖例開關、色彩輔助及名稱顯示偏好，沒有跨裝置同步。從 v1 遷移時保留視角、軸與選取，但初次收起舊面板。本分頁的探索歷程另用 sessionStorage 保存搜尋與類型，重新整理可接續；舊相機快照會正規化為固定全覽；一般顯示偏好仍使用 localStorage。初始資料隨版本保存。提供完整 JSON 匯出與本機版本匯入，可先預覽差異再套用或回復；尚未提供逐欄編輯表單。

文字與選項集中在預設收合的區塊；主題摘要與核心問題在打開詳情後顯示，評分、範圍、關係及來源另行展開。橫軸、縱軸、預設配對、交換軸、完整／未定位數量與恢復預設獨立放在畫面正上方，座標視角常駐；桌面並排、窄螢幕直排。點圖上軸名稱會聚焦對應選單；定義與評分說明仍收在探索設定中。資料仍為原有 48 主題、72 關係、27 來源；原有六階段功能保留，另完成固定全覽小點與常駐雙圖改版。

## 常駐換軸與平滑過渡

`axis-dock` 獨立於探索面板，僅座標視角顯示。圖面為上方卡片預留固定高度，不因設定開關變更布局。下拉欄位沿用本站 P／M／S／R 定義，不把參考圖片中的其他專案指標帶入資料。完整與未定位數量以全部資料計算，未定位含缺值、待評估與不適用。

換橫軸、縱軸、預設配對、交換、恢復預設及返回不同軸時，以主題 ID 對應新舊點位，使用 nominal 650 ms 的三次緩入緩出插值。名稱隨點移動，命中位置逐幀更新。快速連續換軸從目前可見位置接續，取消舊時間線，不累積動畫；中途選點或改顯示偏好亦可接續。初始載入不播放換軸動畫。視圖切換會取消過渡；系統 prefers-reduced-motion 使用直接定位。

進出未定位區的主題，過渡期間由暫時 SVG 點連接中央座標與下方空心點位置，完成後回到原按鈕；不新增主題或寫回插值座標。縮小視窗時維持固定全覽，密集處普通點可小幅縮小；目前選取的外圈保留醒目標示。

## 總覽定位樹（第三階段）

關係視角的樹形按鈕或底部位置列開啟輔助收錄樹；預設收合，開關偏好可保存。常駐的全域地圖是主要定位視圖。它使用固定畫布上方的浮層，不觸發主圖重排或縮放。桌面在左側，手機高 44dvh，保留主圖中心可見。探索設定與定位樹共用左側位置；小螢幕只顯示一個主要浮層。

只有已確認「收錄於」建立樹的上下層，方向從父主題到子主題顯示。第一層為最上層收錄主題，層數是內容編排路徑長度，不是難度、重要性或物理包含深度。原資料 35 筆收錄邊形成 7 個根分支、6 個未分層主題；所有 48 個主題都可由總覽找到。企業、設備及未收錄模型仍可有其他關係，沒有強塞到人工分類。

主圖選取自動更新定位樹與路徑；點樹的名稱更新主圖，不自動打開詳情。定位鈕展開並捲到目前路徑；路徑按鈕可返回上層。所有樹分支共用完整資料，不受主圖篩選刪除；不符合篩選者變淡，選取時可明確清除篩選顯示。多父層保留多條路徑，提供路徑切換；同一 ID 的重複出現不會增加主題總數。循環路徑中斷且標記待釐清，不生成虛構層數。

樹的上下方向鍵移動、左右展開收合、Enter 選取，原生按鈕也可 Tab 操作。分支展開狀態只在本次頁面保留，重新載入會重建目前主題的路徑。目前資料本身沒有多父層或循環；此兩類防護用獨立測試資料驗證。

## 關係樣式與圖例（第四階段）

17 種具名關係各自有固定箭頭形狀與線型，並用 5 個低彩度色系輔助分組。這些分組只服務閱讀，不修改收錄樹或科學定義。黑白模式保留不同箭頭形狀、空心／實心與線型；圖例與主圖共用同一份樣式定義。新增 relation.kind 時須在 `relation-style.mjs` 加入明確樣式並驗證唯一性；未知種類有標示為未定義的 fallback。

| 視覺分組 | 箭頭 | 種類數 |
| --- | --- | --- |
| 編排與分類 | 空心三角 | 3 |
| 機制與模型 | 雙折線箭頭 | 2 |
| 使用與結構 | 開放箭頭 | 5 |
| 作用與整合 | 實心三角 | 5 |
| 產業供應 | 帶橫槓實心箭頭 | 2 |

各組內使用實線、長虛線、短虛線、點線與點劃線作精確區分。箭頭按 from → to，讀作「A〔kind〕B」。每筆已確認關係都有自己的曲線，不再把同一對主題的多種關係合成一條；並行曲線端點適度分開，逆向邊保留自己的起點與箭頭。曲率與線寬不代表資料量。

關係視角的箭頭圖示開啟右側浮動圖例，預設只列當前圖中的種類和條數。可展開查看全部 17 種；目前未出現者不可聚焦。點圖例只淡化其他連線，不刪資料或移動節點；關閉圖例會清除聚焦。圖例與主題／關係詳情交替使用右側位置，手機只開一個主面板。色彩輔助可關閉並記住偏好；主題及連線名稱預設開啟，可沿用顯示設定關閉。

## 探索歷程與返回（第五階段）

右上角兩個小箭頭返回／前進，沒有新增常駐文字。完整清單收在探索設定的「探索歷程」，預設收合，可直接跳到任一位置或清空紀錄並保留目前位置。清單與原設定共用覆蓋面板；不改變畫布尺寸或主圖幾何。

切換主題、座標／關係視角、換軸、搜尋、主題類型、關係種類及多重收錄路徑會形成位置。搜尋在連續輸入停頓 450 ms 後合成一筆；尚未停頓就跳轉時先保存該次搜尋。面板開關只更新當前位置，不新增步驟；圖面固定適應畫面。返回後前往另一個位置會取代原有後續分支，顯示偏好不隨返回改變。

離開前保存主題、軸、篩選、收錄路徑和主要面板；返回時還原。同尺寸下固定布局可恢復；尺寸變更時重新適應。舊歷程中的相機值不再套用，統一為 zoom=1、pan=0。小螢幕仍依單面板規則收合。關係詳情是暫時查閱，不保存為位置；重合成員對話框已移除。瀏覽器本身的上一頁快捷鍵沒有被攔截。

同分頁以 sessionStorage 最多保留 60 個位置，重新整理可接續，沒有跨裝置同步或永久書籤。儲存讀取驗證主題 ID、軸、篩選與有限相機數值；損壞或不適用的歷程會安全回到當前有效位置。儲存不可用時仍能在目前頁面返回，並在收合說明中告知。清空歷程只影響探索紀錄，不刪除知識資料。

## 資料匯入與回復（第六階段）

入口在探索設定的「資料匯入與回復」，預設收合，共用原覆蓋式面板。可以選擇 JSON 檔或貼上完整 JSON；先檢查再預覽，使用者點「套用此版本」才替換資料。預覽列出主題／關係／來源的新增、修改、移除及順序變化；展開個別項目可查看每個欄位的原值與新值。欄位內容按需建立，避免大檔案預先展開大量 DOM。

以匯出的 JSON 當作模板，在外部修改後再匯入。套用的是完整資料集，不是部分合併。上限為單檔 1 MB、600 主題、4000 關係、1200 來源。檢查陣列及文字型別、唯一安全 ID、必要內容、日期、HTTPS 來源 URL、合法分數／狀態、引用、端點與收錄依據。收錄循環須先釐清修正，拒絕匯入；新的非收錄關係種類允許使用通用箭頭，但預覽會提示尚無專屬樣式。格式通過不等於科學內容或文獻支持已重新查核。

目前資料與一個回復點以單次 localStorage 寫入，保存失敗不套用。可預覽並回復上一版，或預覽並還原網站內建版本；還原內建後仍可回復剛才的自訂版本。回復一次後消耗該回復點。重新整理可接續資料，清除瀏覽器儲存會移除本機版本，使用匯出檔備份或轉移裝置。其他已開分頁須重新整理；如果其他分頁先更新，過期分頁的套用會被攔下。這不修改網站發布的共用資料，也沒有跨裝置同步。

套用後重新建立選項、定位樹、關係圖例及完整資料計數，保留有效選取與座標軸，重新以固定全覽布局。失效選取與篩選會校正，探索歷程重建為目前一個位置；自訂資料的歷程以資料簽章隔離。未知或待評估主題仍依當前軸進入未定位區；空資料可顯示空狀態並回復。匯出永遠包含目前完整資料，不受畫面篩選影響。

名稱預設調整：由 v2 升級時保留其他顯示偏好，將兩種名稱一次預設為開啟；之後手動關閉仍會保存，不會每次重新整理都強制打開。

## 新增內容

1. 建立不依賴名稱或順序的穩定 ID，填名稱、english、aliases、types、核心問題、summary、scope。
2. 實際讀取來源，加入來源標題、HTTPS URL、supports、checkedAt；不要用來源支持編輯分數。
3. 為 P、M 各填 status、value、reason、updatedAt、method。範圍尚未評估用 pending。
4. 加入具來源與情境的關係，指定 from、to、kind、condition、sources、status、basis、checkedAt。收錄決策需 basis=editorial；不因距離近或名稱相似新增關係。
5. 更新 data.updatedAt，執行 `node tests/core.test.mjs`。若不再是 48 個起始主題，調整測試的資料集筆數預期；不得放寬核心定位與計數條件。
6. 自用版本可從網頁選檔或貼上 JSON，檢查差異再套用；網站內建資料則透過 Sites 預覽與發布流程更新。

`resources` 已保留給未來圖像、互動單元或外部筆記；本版無內容即不顯示入口。資料匯入與回復已完成。下一個擴充方向是從既有主題開啟最小互動圖解，沿用目前資料來源與返回路徑。

## 查核原則與範圍

穩定物理原理使用 MIT 教材；製程、企業與平台角色使用 ASML、台積電、日月光、Amkor、TI、Applied Materials、Synopsys、Micron 與 KU Leuven 官方內容；焊點界面使用 NIST 原始研究及 2018 年 Sn/Cu 研究。日期統一為實際本次查核日 2026-10-29，不表示每頁都在當天更新。刻意不收錄未查核的客戶、排名、產能或製程尺寸。

重要區分：載子擴散／摻雜原子擴散／界面互擴散；ALD 每循環不保證整整一個原子層；CoWoS-S／R／L 不具有完全相同中介層；WLP 不是單一固定流程；測試不是唯一末端步驟；來源是內容依據，評分是編輯判斷。
