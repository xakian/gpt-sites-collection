需要 Node.js 20 以上。在本資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:4187/ 。免安裝、免建置、無第三方執行依賴。也可將 `dist/` 交由一般靜態伺服器提供；不要直接用 file:// 開啟 ES modules。
