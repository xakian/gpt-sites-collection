# 微影到蝕刻：圖案怎麼留下來

主題 v1.0.0；共用規格 v1.0；共用觀看程式範本 1.0.0。獨立私人 Site，原 SOIC-8 與供應鏈專案不修改。

## 觀看與操作

32 秒一輪，固定局部剖面，追蹤同一塊樣品。七段為準備表面、塗佈與軟烤、曝光、顯影、蝕刻、去膠、觀看結果。完成樣品往右離場，新樣品由左進場。

開啟自動播放；右上播放／暫停、重播、說明；底部速度 0.5／1／1.5／2 倍。全寬原生時間拉桿貼底，可點選與拖曳；定位後保持暫停。方向鍵微調、Home／End 到首尾。主場景取得焦點時空白鍵切換播放。

說明開啟即暫停，關閉仍暫停。「播放接續」收起面板並繼續。下拉選步只換筆記，「定位此步」才改時間。

系統減少動態的設計行為是初始停在 29.2 秒完成態，第一次明確播放從頭開始。執行中切成減少動態會暫停；切回不自動播放。

## 本機啟動

需要 Node.js 20 或更新版本。在本資料夾執行 `node server.mjs`，開啟 http://127.0.0.1:4176/ 。不需要安裝套件、外部資產、建置或後端。Ctrl+C 停止。

使用模組，請經 HTTP 開啟。`PORT` 可指定其他本機連接埠。

## 檔案分工

- `dist/shared/`：直接複用已保存的 1.0.0 範本；本次未改範本。
- `dist/topic.js`：七段資料、代表幀、純時間狀態與材料移除順序。
- `dist/layout.js`：桌面／手機剖面尺寸，文字保持實際像素大小。
- `dist/scene.js`：SVG 物件及由狀態更新的幾何；沒有獨立動畫排程。
- `dist/materials.css`：主題材料色與補充圖；一般控制仍由共用樣式處理。
- `dist/app.js`：接合場景、播放器與說明面板。

## 科學選擇與簡化

矽基板上單層二氧化矽、傳統正型光阻、透射式光罩、簡化投影與方向性較強的乾式蝕刻。曝光只改性質；顯影移除受光光阻；蝕刻移除窗口下薄膜；去膠移除剩餘光阻。薄膜不會在曝光／顯影時消失，也不會在去膠後補回。

不是特定量產配方。尺度、速率與 32 秒時長是示意；光學、軟烤、沖洗、乾燥、材料選擇性與蝕刻終點皆有簡化。光阻在蝕刻中略有消耗。圖案只完成一層薄膜，不代表完整晶片。詳見網站內的收合說明及四項原廠／材料供應商來源。

`?qa` 只在 localhost／127.0.0.1 顯示驗收定位欄位；`?qa&motion=reduce` 只供軟體初始狀態檢查。正式站不開放這個驗收欄位。
