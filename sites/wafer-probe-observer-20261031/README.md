# 晶圓探針測試｜科學觀察動畫

這是一個可獨立執行的繁體中文觀察式動畫，集中回答：**「晶圓還沒切開之前，怎麼知道哪些晶粒通過測試？」**

看同一片晶圓上的晶粒依序對準探針、建立暫時電接觸、接受電性測試，再把結果寫入相同位置的晶圓圖。動畫本身是主角；說明、科學來源與判讀限制需要時才打開。

## 不需要懂程式，也可以在自己的電腦觀看

需要 **Node.js 20 或更新版本**。主動畫沒有第三方執行依賴，不需要安裝套件或先做建置。

1. 解壓縮完整來源包，保留檔案與資料夾的相對位置。
2. 在含有本 README、`package.json` 與 `server.mjs` 的專案資料夾開啟終端機；Windows 可使用 PowerShell。
3. 輸入下列指令並保持終端機開著：

   ```sh
   node server.mjs
   ```

4. 當終端機顯示網址後，在同一部電腦的瀏覽器開啟 <http://127.0.0.1:4175/>。
5. 看完後，在終端機按 `Ctrl+C` 關閉本機服務。

也可用 `npm start` 啟動，效果相同。若不確定 Node.js 是否已安裝，可在終端機輸入 `node --version` 查看版本；若系統找不到指令，需先安裝 Node.js。

請透過上述本機網址開啟。直接雙擊 `dist/index.html` 可能受瀏覽器對 JavaScript 模組的檔案存取限制，不能用來判斷作品是否能執行。

本機網址只在執行服務的同一部電腦使用；它不是正式私人站的登入測試，也不會自動發佈或修改任何網站。

## 怎麼操作

| 控制 | 行為 |
| --- | --- |
| 右上方播放／暫停 | 全場景與時間一起停下；接續保留原進度。 |
| 右上方重播 | 從本輪起點重新開始播放。 |
| 右上方說明 | 開啟觀察筆記並暫停；關閉後仍暫停。 |
| 面板「播放接續」 | 收合說明並從目前位置繼續。 |
| 底部速度 | 0.5、1、1.5、2 倍，切換時保留進度。 |
| 全寬底部進度拉桿 | 點選或連續拖曳到任意位置；定位後保持暫停。 |
| 面板的階段選單 | 只改目前閱讀的說明，不會立即跳動動畫。 |
| 「定位此步」 | 跳到所選階段的代表畫面、收合面板並保持暫停。 |
| 「全部關鍵幀」 | 展開 13 個可直接定位的代表畫面。 |

鍵盤可用 `Tab` 移動焦點；拉桿支援方向鍵、`Home` 與 `End`。焦點在動畫區時，空白鍵可暫停／接續。說明面板可用關閉按鈕或 `Escape` 收起。

共用播放器預期會在分頁進入背景時凍結時間，返回後保留原本的播放意圖。系統偏好減少動態時，初始停在第 47 秒的完成總覽；明確按播放才從頭開始。執行中切換為減少動態會暫停。這些行為的實際環境驗證範圍，仍以驗收紀錄為準。

## 這一輪會看到什麼

完整一輪 **54 秒**：前兩顆慢看接觸與判讀，其餘 35 顆加快巡測，最後保留完成結果，再以遮幕交代重新觀看同一段示意。

| 時段 | 觀察重點 |
| --- | --- |
| 0–3 秒 | 完整晶圓與位置索引；工作台 XY 對準第一顆。 |
| 3–13 秒 | 第一顆上升接觸、施加訊號、量測、比較、記錄通過、下降分離。 |
| 13–23 秒 | 分離後移到第二顆，重複測試並記錄未通過。 |
| 23–45 秒 | 其餘位置依相同順序逐顆巡測。 |
| 45–50 秒 | 晶圓仍完整；晶圓圖保留每顆的結果。 |
| 50–54 秒 | 遮幕表示本輪觀察結束；不是物理過程倒轉或刪除產線紀錄。 |

晶圓俯視圖、接觸放大圖與晶圓圖共用晶粒索引。實體晶圓維持材料色；通過／未通過的結果色與 ✓／× 只出現在數位紀錄。

## 科學依據與必要簡化

來源採 JEM、FormFactor、NI 與 Teradyne 的一手資料。每個來源支持的主張、原始網址及使用界線，見 [docs/science-sources.md](docs/science-sources.md)，網站說明面板也能開啟來源。

**54 秒、37 顆晶粒、4 支探針、31 通過與 6 未通過，全部是本片的示意安排。** 示意相對值 0.96／1.28 與允許區間 0.90–1.10 也不是產品規格、實測資料或真實良率。接點、探針、間隙與升降沒有採同一比例。

通過代表符合已執行的測試項目、條件與限值，不能保證所有功能或未來可靠度。未通過也不能單憑畫面確定故障根因。真實設備可能同時測多顆、進行重測或使用更多分類；本版保留單顆測試與位置登記這條核心關係。[科學依據與判讀限制](docs/science-sources.md)

| `records/acceptance.md` | 根代理實際驗收後記錄的結果、環境、修正及未測事項。 |

主題狀態由 `stateAt(毫秒)` 純計算；它不建立另一個時鐘。整個動畫沿用 `PlayerClock` 的單一時間來源與單一 RAF。拖曳到任意時間都重新計算當下狀態，因此不必先從第一秒播放才能得到正確結果。

維護說明時，階段專屬文字位於 `app.js` 的 `notes` 陣列；通用來源與簡化內容位於 `notes.html`，其樣板需同步至 `index.html`。另開新主題時應建立新副本與新網站識別，不沿用本主題或既有站的發佈身份。
