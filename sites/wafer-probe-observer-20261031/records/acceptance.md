# 晶圓探針測試 1.0.0｜實際驗收紀錄

日期：2026-10-31（台灣時間）。共用規格 v1.0；共用程式範本 1.0.0。

## 環境與證據界線

實作在本次新專案目錄完成；以 Sites 管理的靜態預覽服務 `http://terminal.local:4173/` 實際啟動。使用雲端 Chrome 與 cua_repl 進行真實 DOM／指標／鍵盤操作。此瀏覽器未提供外層 viewport 調整介面，五種尺寸使用相同來源 iframe 的實際 viewport；CSS media queries、dvh 與 ResizeObserver 依該 iframe 寬高運作。這不是實體手機或 Safari／Firefox 測試。

當次瀏覽器的連續播放稽核樣本中位間隔約 1,016 毫秒（記錄本身有最短 250 毫秒採樣條件，並非每個 RAF 的完整清單）；因此完整循環與狀態可以驗證，但不能據此宣稱每一動態幀、60 fps 流暢度或快速巡測的所有接觸瞬間已在正常更新率下看清。另以直接定位補看全部關鍵幀與主要邊界。軟體初始減少動態測試與實際系統偏好測試分開記錄。

## 修正紀錄

1. 對放大晶圓表面新增隨 Z 位移的裁切，避免相鄰晶粒出現在基板外或工作台下方。
2. 以接觸區自己的高度決定緊湊排列，避免小手機的 ATE 與探針卡重疊。
3. 為圖底標示保留實際字高，將矮視窗物件名稱移入可見區。
4. 讀回路徑改由接點朝測試機方向揭露；Z 使用雙向軸提示。
5. 量測階段顯示量測中，完成後才顯示讀值與示意允許範圍。
6. 對位途中改用「對位至／XY 對位中」，接近接觸時明示「正在接近」，避免目標與當前位置混淆。
7. 新主題 CSS 將外層 dialog 設為 `overflow:clip`，讓焦點捲動留在內文容器；實測外層 scrollTop=0。此為主題層修正，未改 canonical 或 shared/ 原檔。

## 未測與限制

| 項目 | 狀態／具體原因 |
| --- | --- |
| 真實背景返回：原本播放 | 未測。建立第二分頁後，原頁與新頁都回報 `document.hidden=false`、`visibilityState=visible`；無法形成真實背景情境。沒有以自製 hidden 事件或暫停開關替代。 |
| 真實背景返回：原本暫停 | 未測，原因同上；一般暫停保持行為已測，但不冒充背景驗證。 |
| 系統／瀏覽器減少動態初始狀態 | 未測。工具不提供媒體偏好模擬；嘗試讀取 `chrome://settings/accessibility` 被瀏覽器 URL 政策拒絕，未繞過限制。 |
| 執行中切換實際 reduced-motion 偏好 | 未測，原因同上。共用程式有對應事件處理，但程式存在不是實測證據。 |
| 正常更新率下的逐幀連續性 | 未完整驗證。雲端回呼約每秒一次，快速巡測部分瞬間被跳過；主要邊界另做直接定位，所有機構邊界另有模型測試。 |
| 實體手機觸控、安全區與瀏海 | 未測；當前為 Chrome 內嵌 viewport，並非真機。 |
| Safari、Firefox 與其他瀏覽器 | 未測，當次未提供這些環境。 |
| 登出、全新登入與其他帳號的拒絕存取 | 待正式站驗收後補記；不會為測試而登出使用者或放寬權限。 |
