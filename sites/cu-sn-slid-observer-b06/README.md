# 銅錫瞬態液相接合

批次06／3；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4603/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

以足量銅、有限錫的平面接點觀察 SLID。保溫約300°C只作機制示例，非製程配方。初期 Cu₆Sn₅ 與 Cu₃Sn 可同時成長，前者較主要；本例止於游離錫耗盡、兩種固態化合物並存，不宣稱已完全轉成 Cu₃Sn。層厚與原子標記均為定性示意，不代表摩爾數、真實密度、速率或可靠度。表面處理、保溫與冷卻時間壓縮。
