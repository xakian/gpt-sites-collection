## 觀察安排

固定的單顆平面增強型 nMOS 剖面，24 秒六段：低閘壓 → 表面耗盡 → 反轉通道 → 載子流動 → 降壓消退 → 回到關閉。源極與基體 0 V、汲極 +0.10 V；閘極電壓示意地從 0 到 1.0 V 再返回。絕緣層與器件幾何不變，循環接縫接回同一顆元件的關閉狀態。

此處的電壓、示意臨界約 0.45 V、粒子數、比例和時間均非計算或量測結果。小汲源偏壓下用長通道線性區直覺；弱反轉、漏電、閘極充放電等見說明面板。來源與逐項驗收見 `來源與簡化.md` 和 `../../records/mosfet-gate-current/驗收.md`。
