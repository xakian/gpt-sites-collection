# 新增主題內容單 · MOSFET

填寫日期：2026-10-31。採用共用規格 v1.0、程式範本 1.0.0、主題網站 1.0.0。本次範圍：新建、驗收並私人發佈獨立網站。

## 想看懂的問題

閘極與矽隔著絕緣層，為何改變閘極電壓仍能控制源汲之間的電流？

## 必要物件與偏壓

單顆平面增強型 nMOS 的閘極 G、完整絕緣層、p 型矽基體 B、n⁺ 源極 S 和汲極 D。S=B=0 V，D=+0.10 V。G 相對 S 從 0 V 示意地升到 1.0 V，再降回 0 V。V<sub>T</sub>≈0.45 V 只是本示意模型的提示值。

## 24 秒觀察腳本

| 時間 | 畫面 | 重點 |
| --- | --- | --- |
| 0–3 秒 | 低閘壓 | p 型表面電洞較多，源汲之間無連續強反轉通道。 |
| 3–8 秒 | 緩升閘壓 | 電場穿過完整絕緣層，電洞退開，表面逐漸耗盡。 |
| 8–12 秒 | 形成反轉 | 表面電子漸增，矽內的通道連接源汲。 |
| 12–17 秒 | 維持導通 | 代表性電子群由源往汲；傳統電流由汲往源。 |
| 17–22 秒 | 緩降閘壓 | 表面電子與導電示意連續減弱。 |
| 22–24 秒 | 回到關閉 | 幾何與材料不變，接回下一輪的同一顆元件。 |

直接定位的代表幀：1.2、7.0、11.5、15.5、21.5 秒。系統減少動態時採 14.5 秒靜態導通幀，明確播放從 0 秒開始。

## 不能誤解的地方

電場可穿過介電質，電子不穿越絕緣層；反轉通道是矽表面的電荷分布，不是新增材料。臨界附近是連續變化，關閉不等於絕對零漏電。粒子點是群體分布的動畫符號，不代表逐顆電子軌跡。閘極充放電、弱反轉與其他省略在面板交代。
