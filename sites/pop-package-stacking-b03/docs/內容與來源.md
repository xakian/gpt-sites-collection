# PoP 封裝堆疊

兩個完整封裝，上下接成一組

採傳統周邊PoP、two-pass路線。本輪僅示範載具內的第一次封裝間迴焊；整組之後才裝主板並經第二次迴焊。TI文件整體較推薦one-pass，本圖因觀察範圍而選two-pass，不代表製程優劣。

助焊採上層焊球受控沾助焊劑的示意，依TI第7.1節的接點準備機制；該節量產例是one-pass，本圖將機制接入two-pass教學模型，並非TI驗證過的專用配方。沾液槽在上方作業區進退，工具在放置後離開。

中央模封凸起低於上層基板，焊點只潤濕各自焊墊。下層底部球同樣受熱，以附著墊面與表面張力保持，載具支撐基板邊緣而不碰球；實際載具、翹曲與熱剖面需另行驗證。

上下封裝已完成，內部元件僅用輪廓識別，不展開打線或倒裝。綠色虛線是定性連通路徑，經基板橫向走線轉接，不是貫穿所有球的一根金屬柱。尺寸、球距與潤濕形變放大；不提供溫度配方。

## 關鍵幀與腳本

3秒 兩個完整封裝：上層有底部焊球；下層有頂面周邊焊墊，另有待裝板底部焊球。 載具只托住下層基板邊緣，中央模封凸起仍需避讓。

7秒 焊球沾助焊劑：上層焊球底端接觸受控深度的助焊劑，沾液槽退出。 助焊劑促進接合，不是永久的承重膠或額外金屬柱。

12秒 上下對準：工具移動上層，使周邊焊球對準下層頂面焊墊。 下層底部球的位置與上層接點不同，不能畫成直通柱。

16.5秒 放置後工具退出：上層下降，球接觸各自焊墊；中央仍避開模封凸起。 夾持工具退出後，兩個完整封裝連同載具進入迴焊。

21秒 第一次迴焊：封裝間焊料熔融、潤濕對應焊墊，形成分離的接點。 底部球也受熱，仍附著原墊且不接觸載具；無相鄰橋接。

25秒 冷卻凝固：焊點冷卻成形，保留上下封裝中央間隙。 底部端子保存，尚未接上主板。

27秒 堆疊件移交：顯示封裝間連通與待裝板端子，完成件隨載具離開。 下一輪是新的兩個封裝；已形成焊點不拆回焊球。
