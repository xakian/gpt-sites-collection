# 矽玻璃陽極接合

批次06／4；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4604/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

採含鹼硼矽玻璃與矽，玻璃在上、矽在下；矽端較正、玻璃外側較負。中央小空腔不參與接觸。Na⁺數量、耗盡區厚度及Si—O符號放大；只示意淨遷移與界面反應，不求解電場、空間電荷或反應速率。工業電壓與溫度依材料而異，本片不提供通用配方；接合完成仍須測漏。
