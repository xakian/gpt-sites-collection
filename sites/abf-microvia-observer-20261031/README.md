# ABF 載板增層與微盲孔

批次 04／01。共用規格 v1.0；共用程式範本 1.0.0（由 starter 複製，未修改共用檔）；主題 1.0.0。

執行 `node server.mjs`，開啟 http://127.0.0.1:4241/ 。免建置，無第三方執行依賴。正式發佈使用 dist/。

34 秒，10 個階段。模型在 dist/model.js，材料在 materials.js，SVG 圖形與布局在 drawing.js，播放接合在 app.js。`?qa` 暴露本題觀察狀態供驗收；`?qa&motion=reduce` 是軟體強制初始測試，不是系統偏好測試。

關鍵幀：1.8、5.8、9.8、12.8、16.8、19.8、24.8、27.9、30、32.5 秒。代表同一中央捕捉墊；相鄰銅墊保留。覆膜是絕緣樹脂；雷射停在捕捉墊；殘膠清除後才鍍連續薄銅；圖案電鍍後去膜再蝕除外露薄銅；完成件整體退出。

來源及簡化見 dist/index.html 說明面板與 records/abf-microvia/內容與來源.md。測試結果另存 records/abf-microvia/，未測不能以範本結果替代。
