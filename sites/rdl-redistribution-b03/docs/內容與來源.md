# RDL 重佈線層

接點，延伸到晶粒以外

採單層銅半加成法：介電開窗、黏著／銅種子層、圖案化光阻、電鍍、去光阻、去外露種子及黏著層、保護介電層開接點。從準備好的重組面開始，省略各步搬運及清洗。

俯視顯示兩條線，A線剖面同步放大原焊墊的開窗接觸。種子層未蝕除前，兩線經連續薄金屬相連，不能稱為隔離。線下種子與黏著層保留；外露區按銅、黏著層先後移除，圖中合併表示。

電鍍電源負端接種子、正端接陽極。槽液與陽極以功能符號表示；不繪製漂浮粒子代替配線。薄層厚度放大、時間壓縮，不模擬電流分布、蝕刻側蝕或導通數值，不包含CMP、多層RDL或凸塊。

## 關鍵幀與腳本

5秒 介電層開窗：介電層覆蓋重組面，只在原始焊墊上開窗。 未開窗處維持絕緣；右方模封區不是矽。

9秒 連續種子層：薄黏著／銅種子層覆蓋表面並接觸開窗內的焊墊。 種子層先連成一片，為電鍍供電。

14秒 光阻定義配線：圖案化光阻留下兩條配線開口，從晶粒焊墊延伸到外側。 紫色光阻遮住其餘區域。

20秒 通電鍍銅增厚：電源透過連續種子層供電，銅在光阻開口內逐漸增厚。 A線剖面可見金屬經開窗接到原焊墊，沒有隔著介電層導通。

25秒 去除光阻：去光阻後露出兩條厚銅線與線間的薄種子層。 此時仍有連續種子，兩條線還未隔離。

30.5秒 蝕除外露種子：移除線外的種子與黏著層，線下保留，兩條配線才彼此隔離。 薄層消失代表蝕刻移除；不能連同厚銅線一起刪去。

34.5秒 保護層與新接點：保護介電層覆蓋線路，保留外移接點開口。 A、B是彼此分離的兩條配線；未加入凸塊。

36.5秒 完成表面移交：完成表面離開，新待加工表面進場。 成品上的銅線不會倒回消失。
