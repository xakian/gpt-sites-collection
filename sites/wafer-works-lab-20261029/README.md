# 半導體工廠 Wafer Works

依上傳的《半導體產業模擬遊戲 AI 自主開發規格書 v1》製作的單人純前端遊戲。產品是圖案化晶圓試片，不是完整 IC。所有數字為遊戲設計值。

## 遊玩

1. 接教學訂單，依序購買並配置五種設備，總額 1,500 C。
2. 採購一盒晶圓、四種耗材各五份，十模擬秒到貨；光罩已在材料倉。
3. WASD／方向鍵移動，E 執行情境動作，Q 切換附近目標。手機使用搖桿與文字按鈕；點空地也可步行。
4. 取補給盒到對應設備補給，光罩安裝到微影機。拿取晶圓，依序沉積、微影、蝕刻、去光阻清洗、檢查。各站上料後靠近開始配方，完成後取出原盒。
5. 到出貨站確認交貨。首單收入 300 C，餘額 540 C。可花 200 C 聘工。
6. 啟用工人規則後，工人只搬晶圓；玩家仍負責補料、光罩、開工與交貨。取消持物任務會實際返倉，滿倉時可就近接手。

建造時可點格、平移、旋轉，並使用方向按鈕逐格調整。空槽且沒有裝卸或預約的機台可搬遷。首單後可升級至等級 2，加工時間乘 0.8。快速微影 30 秒，固定產生第 19、20 片缺陷。

每十模擬秒自動保存；存檔面板可保存、讀取、備份、JSON 匯出匯入及恢復營運檢查點。保存僅限本瀏覽器，沒有跨裝置同步。背景、建造、設定及手動暫停都停止生產與交期。回到前景需手動恢復。

## 本地執行與測試

無執行依賴，不需要安裝套件、帳戶或 API Key。使用 Node 24 的測試工具：

```sh
npm test
npm run check
python3 -m http.server 8080 --directory dist
```

瀏覽 `http://localhost:8080`。避免 file:// 直接開啟，因 ES 模組與存檔來源限制。

## 專案結構

- `dist/content.mjs`：設備、耗材、路線、配方及訂單定義。
- `dist/core.mjs`：權威狀態、命令驗證、短動作、加工、經濟、不變量。
- `dist/navigation.mjs`：碰撞、最短路徑、建造與可達性。
- `dist/logistics.mjs`：單工人排程、雙預約、實際搬運、返還與接手。
- `dist/persistence.mjs`：版本、快照、備份、故障處理與匯入驗證。
- `dist/render.mjs`：Canvas 視覺；`dist/app.mjs`：DOM、輸入及唯一模擬排程器。
- `tests/`：固定情境與行為測試；不在正式遊戲提供變更狀態的除錯入口。
- `docs/`：決策、進度、限制、驗收報告及瀏覽器證據。

`?qa=1` 僅輸出唯讀測試快照及座標；沒有加錢、改工序或瞬移接口。
