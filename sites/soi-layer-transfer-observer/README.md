# SOI薄層轉移 1.0.0

第二批08，規格v1.0／範本1.0.0原樣副本。`node server.mjs`，本機4208，免建置、無第三方執行依賴。

36秒Smart Cut類型矽SOI代表流程：已氧化A→H+植入A內→表面準備／水平軸180°翻面→氧化面直接接合B→熱處理／A內部分離→餘料離開薄矽留下→整理→兩產物分流／新A+B。翻面使用同一群組scaleY=cos(angle)的剖面投影，沒有交換顏色冒充翻面；中途變薄是投影。薄矽小點持續追蹤。無膠水或焊球，最後層序薄A/BOX/B；A餘料不恢復厚度。

關鍵幀1、7.9、8.9、11.5、13.9、18.9、23、27.5、31.5、33、35。分鏡、來源與簡化見dist/model.js；drawing.js保存幾何布局。驗收及部署見../../records/soi-layer-transfer/。
