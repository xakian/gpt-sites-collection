# 氣密封裝氦氣測漏

批次05／7，主題1.0.0，規格v1.0，範本1.0.0。網站身分已保存在 .openai/hosting.json；不得重建或改變私人存取。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4507/ 。Node.js20+，免安裝／免建置。dist可直接由靜態HTTP伺服器提供。
