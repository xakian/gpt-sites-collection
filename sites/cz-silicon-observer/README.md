# 單晶矽拉晶：一顆晶種怎麼長成整根晶棒？

繁體中文、獨立私人 CZ 觀察動畫。主題 **1.0.0**，共用規格 **v1.0**，共用程式範本 **1.0.0**。建立日期：2026-10-31。

正式網址：https://cz-silicon-observer.fishddry.chatgpt.site/

發佈結果以專案根目錄 `records/cz-silicon/publication.json` 為準。擁有者私人；沒有改動既有網站、canonical 範本或其他主題。

## 執行

需要 Node.js 20 以上，不需安裝套件。在本資料夾執行：

```text
node server.mjs
```

瀏覽器開啟 http://127.0.0.1:4199/ 。若連接埠已被其他工作占用，請換用未使用的連接埠，不停止其他主題的伺服器。

驗證模型與時鐘：

```text
node --test tests/*.test.js
```

本機實測 Node.js v24.22.1。系統沒有 `npm` 命令；上述直接執行方式不需要 npm。

## 觀看

48 秒／8 階段：新原料熔化 → 接種 → 細頸 → 肩部 → 等徑段 → 尾錐 → 冷卻取出 → 新爐次。

頁首暫停／接續、重播與說明；底部四速度和可點選、拖曳的時間軸。拖曳後保持暫停。Tab 操作控制，時間軸支援方向鍵與 Home／End；畫布聚焦後空白鍵播放／暫停。說明選段不跳時間，「定位此步」才定位；關閉仍暫停，「播放接續」才播放。

## 檔案

- `dist/model.js`：純時間狀態、連續軸向輪廓、體積積分與爐次。
- `dist/scene.js`：SVG 設備、晶種、同一根晶棒、熔體、界面及局部排列。
- `dist/layout.js`：設備與局部圖布局。窄螢幕的原子圖改放說明。
- `dist/materials.css`：材料及主題樣式。
- `dist/app.js`：共用播放器接合與說明定位。
- `dist/shared/`：canonical 1.0.0 的原樣副本及 SHA-256 清單。
- `docs/內容單.md`、`docs/來源與簡化.md`、`docs/驗收紀錄.md`：內容決策與實際證據範圍。
