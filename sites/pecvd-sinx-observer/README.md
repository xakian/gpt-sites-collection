# PECVD SiNx 1.0.0

第二批03。共用規格v1.0、範本1.0.0。`node server.mjs`，http://127.0.0.1:4203 。免建置、無第三方執行依賴。

30秒電容耦合PECVD概念模型：SiH₄／NH₃／N₂，上方RF噴淋頭與下方加熱載台，淺台階表面連續沉積SiNₓ。分開電子、離子、中性活性物種與排出氣體，停機膜保留，換新基板循環。

關鍵幀2、5.5、8.5、13、20、25、27、29秒。`model.js`保存純狀態、來源與簡化；`drawing.js`保存材料幾何與響應布局；`app.js`接上原樣共享播放器。未提供設備配方。

網站身分見hosting.json，逐項驗收／發佈證據在../../records/pecvd-sinx/。
