# 台灣半導體產業知識座標圖

繁體中文互動知識圖。以圖為入口，靜態 HTML/CSS/ES modules，無第三方前端依賴。正式內容以本 GitHub 儲存庫為準，不再與 GPT Sites 同步。

## 使用

進入後直接顯示全畫面座標圖，沒有大標題、企業啟動列或常駐側欄。點圓點開啟單元；數字圓點先展開同座標清單。浮動卡片只先顯示一句定義與相關連結；內容、問答、分類、來源、關係和評分依據均按需展開。可從卡片繼續點進其他單元。

直接點座標軸名稱切換維度；拖曳平移、滾輪或雙指縮放，右下角回到全圖。左上角收納搜尋及進階篩選，右上角收納說明、企業比較、評分規則與本機筆記工具。數字圓點與單點皆可用鍵盤 Enter／空白鍵開啟，Escape 關閉浮動面板，Ctrl／⌘ K 開啟搜尋。

本機筆記修改保存在目前瀏覽器的 localStorage，不會更動 GitHub 或正式網站。不同裝置不會自動同步；清除網站資料將清除修改。JSON 格式含 schemaVersion、nodes、relations、dimensions、評分規則與來源日期。既有儲存鍵與資料格式保持不變。

## 資料

初版 60 個知識單元、16 個企業法人。日月光投控與日月光半導體分開保存。資料截至 2026-10-28 查核；未標發布日期的官方頁面如實標記。業務類型、產業活動、產品技術與應用分欄。主要／其他是編輯選擇的業務重心，不是營收比例。企業分數描述其概況的知識特性，不評等公司能力。

實際具名股權關係附官方清單；其他知識連結與定位分析均標明分析性解釋，通訊晶片旅程為典型流程示意。來源詳見節點來源分頁。

## 本機開發

目前 Vercel 直接服務追蹤中的 `dist/`；在本目錄執行 `python -m http.server 4381 --bind 127.0.0.1 --directory dist`，開啟 `http://127.0.0.1:4381/` 即可本機預覽。介面主要位於 `dist/index.html`、`dist/app.js`、`dist/explore.css`；既有表單及對話框沿用 `dist/style.css`。

`node assemble.mjs` 從 `data/` 產生種子資料；只有修改資料時才需執行。`node tests.mjs` 驗證資料、20 組座標、聚合、引用、分類、JSON round trip、無效匯入及缺分。該測試會輸出 `verification.json`，初次遷移紀錄應保留，日後測試結果另記，不覆蓋歷史證據。

2026-10-31 使用者已確認精簡版發布。`codex/**` 分支不產生 Vercel 自動預覽；正式分支以省用量腳本比較上次成功部署，只在本站公開檔案或實質部署設定有變化時發布。此單元沿用原網址，主站與其他單元不需重新部署。每次發布前仍須確認餘額與實際差異，發布後核對正式檔案。
