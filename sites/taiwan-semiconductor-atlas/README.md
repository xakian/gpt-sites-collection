# 台灣半導體產業知識座標圖

繁體中文研究工作台。以相同資料支援企業與知識兩個探索入口，靜態 HTML/CSS/ES modules，無第三方前端依賴。

## 使用

從台積電、力積電或日月光入口開始，點選概念連結深入。可切換不同 X/Y 維度，點聚合標記選取同分節點；拖曳平移、滾輪或雙指縮放。企業比較支援 2–3 家；詳情可編輯內容、分類、評分、來源與關係。資料管理提供完整 JSON 備份與驗證後匯入。

修改保存在目前瀏覽器的 localStorage。不同裝置不會自動同步；清除網站資料將清除修改。JSON 格式含 schemaVersion、nodes、relations、dimensions、評分規則與來源日期。

## 資料

初版 60 個知識單元、16 個企業法人。日月光投控與日月光半導體分開保存。資料截至 2026-10-28 查核；未標發布日期的官方頁面如實標記。業務類型、產業活動、產品技術與應用分欄。主要／其他是編輯選擇的業務重心，不是營收比例。企業分數描述其概況的知識特性，不評等公司能力。

實際具名股權關係附官方清單；其他知識連結與定位分析均標明分析性解釋，通訊晶片旅程為典型流程示意。來源詳見節點來源分頁。

## 本機開發

Sites preview 依 `.openai/hosting.json` 服務 `dist/`。`node assemble.mjs` 從 `data/` 產生種子資料；`node tests.mjs` 驗證資料、20 組座標、聚合、引用、分類、JSON round trip、無效匯入及缺分。

## 驗證

瀏覽器已實測座標切換、同分清單與節點跳轉、三家並排比較、評分編輯與重新整理保留、下載 JSON 與重匯入、錯誤 JSON 拒絕、新增維度與待評分、新增節點與關係。瀏覽器資料最後還原初始內容。觸控實作使用 Pointer Events，但本次操作驗證使用桌面瀏覽器。
