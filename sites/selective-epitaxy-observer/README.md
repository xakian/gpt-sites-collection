# 選擇性矽磊晶 1.0.0

第二批04。共用規格v1.0、範本1.0.0。`node server.mjs`，http://127.0.0.1:4204 。免建置、無第三方執行依賴。

30秒，Si(100)／SiO₂開窗、DCS/HCl/H₂代表模型。開口前處理後局部成長；氣體同時抵達遮罩與矽，新增矽延續取向，原表面虛線保留。新色只辨識來源，仍是矽。平頂幾何不指定晶面角度。更換完成件與新開窗晶圓循環。

關鍵幀1、6、9、14、22、25、27、29秒。來源／簡化／分鏡在dist/model.js、面板；drawing.js保存SVG幾何與響應布局，app.js接上原樣共用播放器。詳細驗收與部署見../../records/selective-epitaxy/。
