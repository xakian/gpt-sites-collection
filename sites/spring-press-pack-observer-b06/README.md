# 彈簧壓接式功率封裝

批次06／7；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4607/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

依ABB StakPak獨立彈簧壓針與框架限位原理，改編成兩晶粒概念剖面，不是原產品的尺寸圖。晶粒A與B本體厚度固定；下方承托層的高度差放大。各自彈簧行程不同，夾持力由彈簧常數與行程決定，不宣稱兩顆壓力恰好相等。僅顯示主功率接觸區，省略閘極與開關行為；橙箭頭表示力，藍色接面表示已建立金屬電接觸，絕緣框架不是導電路徑。完成件維持外夾持並連同治具退場。
