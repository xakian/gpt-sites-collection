# DBC 陶瓷覆銅接合

批次06／2；主題1.0.0、共用規格v1.0、範本1.0.0。

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4602/ 。免安裝、免建置。

內容單與一手來源見 內容單.json 及 dist/model.js。app.js 沿用未修改的共用控制、單一主時鐘；model.js 保存科學狀態，graphics.js 繪製物件，layout.js 分配響應式位置，svg.js 是本題副本的繪圖小工具。

選已燒成氧化鋁與預處理銅箔的代表路線。銅氧共晶區約1065°C是來源的工業示例，不是通用配方；本片只標受控升溫／冷卻。界面厚度與潤濕前緣放大，主圖與放大區同時採用相同反應進度。略去真實表面粗糙度及氣氛控制細節，未呈現另一側覆銅。
