# 銀燒結固晶

銀保持固態，顆粒逐步連成接合層

採InFORCE MF壓力輔助乾式置晶代表順序：模板印刷、預乾燥、加熱貼放，再壓力燒結。資料表第1頁流程圖確認置晶時基板與晶粒需加熱；本圖省略製程數值，不是可直接使用的溫壓配方。

以鍍銀銅墊及具有相容銀表面金屬化的功率晶粒為例。下方陶瓷提供電氣絕緣，導電虛線只走金屬層，不穿越陶瓷。基板全程有下承托，上壓頭經晶粒傳遞壓力。

濕膏含銀顆粒與有機載體。預乾燥去除大部分揮發成分，後續加熱移除剩餘有機物；淡褐色離開線索僅表示去向，不指定全部成分的化學反應。灰色銀顆粒從未畫成液滴。

A為同一接合層的概念放大圖，粒數與孔隙不按比例。接觸處成頸、頸部擴大，層厚縮小但保留孔隙；連結不是瞬間變成無孔實心銀板。熱與電路徑為定性示意，不代表量測效率。

## 關鍵幀與腳本

5秒 印刷濕銀膏：在已準備的鍍銀墊上印刷銀膏，灰色顆粒分散於褐色載體。 此時不是已完成的實心金屬板；A區放大同一接合層。

10秒 預乾燥：預乾燥去除多數揮發成分，接合層變薄。 仍需後續加熱與壓力，不能把乾燥當成完成燒結。

15秒 加熱貼放晶粒：加熱後，金屬化晶粒背面貼到預乾燥層。 上下相容金屬表面相向，基板下方有支撐。

21秒 加壓與顆粒成頸：施加熱與壓力，顆粒接觸處逐步連結，孔隙縮小。 銀保持固態，主層與放大區同時變薄；孔隙不歸零。

26秒 冷卻與卸載：完成燒結後冷卻，壓頭釋放並退出。 燒結層留在晶粒底下，不回復成濕膏。

28秒 金屬路徑與移交：熱與電可經金屬化背面、燒結銀層到鍍銀銅墊。 陶瓷不在電路徑中；成品離開後，新晶粒與基板進場。
