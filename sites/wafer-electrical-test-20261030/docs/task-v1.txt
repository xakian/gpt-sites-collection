## B 學習目的與範圍

### B1 核心問題

外觀相同的晶粒，測試機如何根據量測結果，判斷它們是否符合指定條件與規格？

### B2 三項理解目標

| ID | 觀眾應理解 | 應從畫面看到的證據 |
| --- | --- | --- |
| L1 | 測試需要建立連接、施加已知條件，再取得回應並比較。 | 接觸前沒有讀值；輸入已知後出現量測；預期值或上限一直有明確位置，判定晚於量測。 |
| L2 | 功能符合不代表所有測項符合。 | A、B 都通過本例兩個邏輯圖樣；A 的靜態供電電流為 2 μA，B 為 14 μA，共用上限 10 μA，因此只有 A 通過本例全部測項。 |
| L3 | 測試結果是有範圍、可追溯至位置的資訊。 | A、B 的結果寫入各自的結果圖格子；晶粒材料和位置關係不變；其餘格子仍未測；結果標「本例兩項」，不寫零缺陷保證。 |

### B3 起點、終點與前提

- 起點：一片已有待測電路、尚未切割的示意晶圓放在晶圓承載台上。探針與 A 對準但未接觸，儀器尚未施加電源，結果圖尚無測試結果。
- 終點：A、B 的兩類測項、總結果及位置紀錄清楚可見；電源與輸入施加已停止，接觸解除，晶粒仍留在晶圓上。
- 前置知識只需：晶圓上有多個晶粒；0、1 表示兩種邏輯狀態；電流是一個可量測、可與上限比較的量。
- 畫面內短註：「緩衝器：輸入 0，預期輸出 0；輸入 1，預期輸出 1。」
- 英文詞首次在說明中配中文：ATE 自動測試設備、prober 晶圓探針機、probe card 探針卡、DUT 待測元件、wafer map 晶圓結果圖。
- 不要求先懂 CMOS 電晶體、掃描鏈、量測儀器介面或測試程式語法。

### B4 本次邊界

以傳統切割前產品晶粒的電性測試作例子。晶圓測試與封裝後測試都是實際存在的測試階段；本動畫只展開前者。[S1、S2]

本次不展開：封裝後測試搬運、失效分析、真實故障定位、多站並測、速度分級、scan／ATPG、記憶體測試演算法、量測誤差與 guard band、重測策略、製程監控 WAT／PCM、可靠度試驗與燒機。功能與電性參數是測項類型，不能把它們分別等同於晶圓階段與封裝階段。[S1、S5]

後續最多三個獨立子題，這次不實作：
1. 封裝後測試：接觸介面改變後，為何仍需測試？
2. 時序與速度分級：功能正確，是否也能在指定速度下正確？
3. 測試覆蓋與可靠度：一次通過能說明什麼，仍有哪些未回答的問題？

### B5 收合區中的理解檢查

以下三題與答案放在「看完想一想」，預設收合，不影響觀看。

1. 問：B 的輸出都正確，為什麼仍未通過？
   答：功能只是一類測項。B 在本例固定條件下的靜態供電電流是 14 μA，高於 10 μA 上限，所以未通過本例全部測項。
2. 問：晶圓結果圖上的叉號，代表那顆晶粒被切掉或變色了嗎？
   答：代表對應位置的測試紀錄。這輪沒有切割、挑料或修復，晶粒仍在原晶圓上。
3. 問：A 通過，是否代表任何溫度、速度與使用時間都不會故障？
   答：不能。這裡只能說 A 通過本例所選測項與條件，沒有檢查所有使用情境或所有故障。[S6]

3. A、B 是同一設計的兩顆晶粒；形狀與接點排列相同。不能在測試前用裂痕、顏色或動畫暗示 B 的結果。
4. 本例不是 TI SN74LVC1G34 產品模擬；只用其官方資料支持緩衝器功能與不同電性量的區別。[S4]
5. 材料只需示意矽晶圓與金屬接點，不指定製程節點、摻雜剖面、真實 pad 版圖或針數。
6. 本動畫採預設測試案例資料加確定性判定，不求解電晶體、暫態電路或電磁場。數字不是實測，也不是 SPICE 求解結果。

### C4 判定規則

在有效接觸、供電及量測條件成立後：

- 功能單圖樣通過：已取樣，且量測邏輯等於該圖樣的預期邏輯。
- 功能項通過：X = 0 與 X = 1 兩個圖樣都已量測、比較且符合。
- 電流項通過：已取得有效靜態電流，且 I_DD ≤ 10 μA。等於上限在本例算通過。
- 總結果：本例兩項都已完成比較後，兩項都通過才顯示「本例通過」；任一項未通過則顯示「本例未通過」。
- 未完成：顯示「待判定」，資料欄為 —，不能用 0、false 或綠色填補缺資料。
- 結果圖：總結果產生後，再於指定記錄時刻更新該晶粒格子；不得預填。
- 這裡選擇「兩項都做完再揭示總結果」是教學安排。真實測試流程可在失敗後跳過後續測項；不得把本例呈現順序說成產業必然規則。[S5]

對照的推論只使用同一組條件與限值。兩顆是刻意選定的案例，不計算或顯示「良率 50%」，也不據此描述真實晶圓分布。

### D3 電性連接與機械錨點

以下是必要拓撲，不是實際機台 CAD：

- VDD 支路必須包含供電與電流量測角色；回路經 DUT 的 GND 回到儀器共用參考。不得把電流表直接橫跨 VDD 與 GND，形成錯誤短路圖。
- 輸入通道接 IN；量測通道接 OUT。任何線條交叉若非接點，不加實心接點；接點有明確端點或圓點。
- 四個示意 pad 依 VDD、IN、OUT、GND 排列，對應四條探針。只是攤開方便閱讀，不能宣稱是真實 pad 排列。
- 以每顆示意晶粒寬 d 作畫面單位，A、B 中心距 p 建議約 1.2d；接點在各晶粒局部寬度約 0.15、0.38、0.62、0.85 處。
- 探針卡與探針 XY 位置固定。承載台帶著整片晶圓及所有晶粒一起移動。
- 初始 A 在探針正下方；從 A 換至 B 時，承載台水平移動 -p。B 的 pad 到達原本 A 的接觸位置。
- Z 接近時台面上升至 pad 與針尖相接；接觸解除時下降，兩者間有清楚間隙。針尖不穿過晶粒。
- 接觸中禁止 XY 平移；四個 pad 必須同時與其對應針尖保持一致。
- 晶圓底部保持連續材料帶，晶粒分界是版圖區域／示意邊界，不能畫成已切割的深溝或分離小方塊。
- A、B ID 綁定晶粒的局部座標，隨台面一起移動。不能把螢幕左邊永遠叫 A、右邊永遠叫 B。
- 桌面可同時看到 A、B；窄螢幕可以裁去非作用晶粒的部分實物，但結果圖與 A、B 身份必須持續可辨。

### D4 結果圖與量尺

結果圖為原創九格示意：中心格 A、中心右格 B，其餘七格為未測。外圍圓只提示晶圓，不表示真實晶粒數、尺寸或空間分布。內部座標可用 A=(row 0, col 0)、B=(row 0, col 1)，兩者是固定 ID。

| 表示 | 唯一意義 |
| --- | --- |
| 格內 — 或空心符號 | 未測；不可與未通過共用符號。 |
| 格內 … | 本輪已開始測試、尚未寫入總結果。 |
| 格內 ✓ | 已寫入「本例通過」。 |
| 格內 × | 已寫入「本例未通過」。 |
| 格子雙外框 | 當前已對準的晶粒；不是結果。 |
| 格子旁 A／B | 穩定身份，與實物及讀值表一致。 |

- 尚未開始 B 時，B 不能預先顯示 ×。
- A 完成後，測 B 的期間 A 紀錄一直保留。
- 其餘七格始終未測；不自動補成一片紅綠棋盤。
- 換晶粒時不讓結果圖整張跟承載台滑動；結果圖是固定座標紀錄，選取外框改指 B。
- 電流量尺標 0、10、20 μA；10 μA 的垂直限值線貫穿 A、B 兩行，保持固定。
- A 取樣點為 2/20 的相對位置，B 為 14/20；用字母與不同列識別，不靠顏色。
- 未取樣的點不存在；不能先放在 0 再滑到讀值，讓人誤認成電流實際上升。
- 取樣後在正確位置淡入標記與精確讀值。淡入只表示資料揭示，不是量測動態或電流累積。
- 功能 0／1 與電流量尺不共用數值座標。

### D6 視覺語義

- 背景近白；材料灰、輪廓深灰、金屬接點低飽和灰褐。例：背景 #FAFAFA、矽示意 #E4E7EA、接點 #B5A58C、文字 #25282D。

- 可適度加深文字與線條以滿足對比，不追求過淡的「極簡」而犧牲可讀性。
- 不用漸層、霓虹、厚陰影、粒子流、機台照片、卡車或道路。

## E 動畫時間表

### E1 時間約定

- 單一主題時間 t，單位為「動畫秒」，範圍 0–40。

## F 本題完整播放規則

### F1 時間與操作

- 一個主時間控制全部圖形、數值揭示、強調、機械位移與重設；使用單一 requestAnimationFrame 驅動。
- 一般初次開啟：t=0、自動播放、1 倍速、說明收合。
- 暫停凍結主時間與所有可見動畫；接續從相同時間開始。
- 提供重播、0.5／1／1.5／2 倍速、五個關鍵步驟定位，以及可鍵盤操作的時間進度控制。
- 調速保持當前 t 與畫面，不把進度重新換算或重播；暫停中調速仍暫停。
- 重播設 t=0 並播放，保留已選速度。
- 直接拖曳進度或定位步驟立即暫停；拖曳結束也不自動接續。
- 拖至 40 s 時停在重設完成的初始畫面，仍暫停；再按播放才進入下一輪。
- 正常播放超過 40 s 時依週期進下一輪；相同週期內的 t 與固定參數必須產生相同畫面。
- 不用 CSS 自行循環的主題動畫、獨立 setInterval 或每個元件自己的時鐘。

### F2 說明與焦點

- 開啟說明先暫停；關閉仍暫停。
- 面板內選取說明只換說明內容，不改主時間；按該說明的「定位此步」才跳轉並維持暫停。
- 按播放會收合面板並從目前 t 接續。
- 所有控制有繁體中文可及名稱、鍵盤入口與可見焦點。
- 面板可用關閉按鈕及 Escape 關閉，關閉後焦點回到開啟它的控制；用播放關閉時焦點留在播放控制。
- 優先用原生 button、select、range；Enter／Space 的按鈕操作不得與全域快捷鍵重複觸發。
- 若設 Space 播放快捷鍵，只在播放器容器或非輸入區適用，不能攔截文字輸入或導致頁面誤捲。
- 不每幀向螢幕閱讀器朗讀讀值；只在使用者操作或階段變化時提供簡短狀態。

### F3 分頁、轉向與減少動態

- 分頁進入背景時凍結時間；返回後保持離開前的播放／暫停意圖，不補算背景 30 秒。
- 背景返回須重設牆鐘基準，避免一幀跳完整輪。
- 調整視窗、手機轉向或重新排版保留主時間、速度與暫停意圖。
- 系統 prefers-reduced-motion 初始開啟時，以 35 s 靜態幀呈現且不自動播放。
- 使用者明確按播放後才允許動畫；播放從目前 35 s 接續，按重播才從 0 s 開始。
- 執行中系統改為減少動態，立即暫停在目前時間；不強制跳到另一幀。
- 系統改回一般動態也不自動播放。
- 暫停時連數值淡入、強調線與重設淡出都要一起停住。
