```sh
node server.mjs
```

開啟 http://127.0.0.1:4178/ 。不需安裝套件或建置。關閉伺服器用 Ctrl+C。

## 操作

頁首：暫停／接續、重播、說明。底部：0.5、1、1.5、2 倍速與全寬進度拉桿。點按、拖曳或鍵盤定位後保持暫停。Tab 移焦；拉桿用方向鍵、Home、End；畫布聚焦時空白鍵切換播放。

說明預設收合。選步不改時間，「定位此步」才跳轉並收合面板；關閉面板仍暫停，「播放接續」收合並播放。背景時間不追補。減少動態時顯示 31 秒完成態，明確按播放才從頭開始。
