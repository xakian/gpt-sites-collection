# DAF 薄膜與階梯式晶粒堆疊

批次 06／01。主題 1.0.0；共用規格 v1.0；canonical 範本副本 1.0.0。

在本目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4601 。無安裝、無建置、無第三方執行依賴。

`dist/model.js` 保存內容單、來源、32 秒七段腳本、關鍵幀及簡化；`graphics.js` 畫材料與物件；`layout.js` 依視窗排列；`app.js` 接入未修改的共用播放控制。單一 timestamp / RAF，由共用 PlayerClock 管理。

採非導電爐固化型 DAF 代表路線。三顆晶粒向同側錯位；② 是追蹤晶粒。框架僅顯示一個取晶窗口，後續晶粒隨膠帶送入。成品與框架退場，新材料進場，不倒拆固化結構。剖切側視、薄膜及焊墊放大、熱歷程與設備節拍壓縮。沒有正式打線與模封。

執行 `node test.mjs` 檢查物件身分、轉段邊界及五尺寸的數值有效性。實際播放記錄位於 `../../records/daf-stair-stack/`。軟體強制減少動態只限 localhost `?qa&motion=reduce`，不等同系統偏好測試。

網站身分保存在 `.openai/hosting.json`；禁止重新註冊同一站。私人網址及部署提交以批次進度為準。維持擁有者私人存取。
