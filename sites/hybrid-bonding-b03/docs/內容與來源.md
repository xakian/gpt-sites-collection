# 混合接合

同一界面，兩種材料接合

採 wafer-to-wafer Cu／SiO₂ 代表模型。從已完成元件、平坦化及清潔的晶圓開始；先表面準備與活化，翻面對準，室溫介電預接合，再退火強化介電接合並完成銅接點。

上片繞水平軸翻面，以剖面厚度的縮短與翻轉表示，不交換左右接點。金色角標與既有導線跟隨上片；兩對銅墊在對準後才靠近。銅表面受控凹陷極度放大，並非實際尺寸。

介電接合前緣用綠色界面線表示，此線不是新增膠層。退火期間銅保持固態；以凹陷逐步閉合表示定性接點形成，不計算熱膨脹、原子擴散或表面化學。電路路徑僅在接點完成後顯示。

不含焊球、熔融液滴或導電膠；不重作前段製程、SOI轉移。imec的Cu／SiCN研究只用於表面及凹陷原理，不挪用其間距、溫度或性能數字。

## 關鍵幀與腳本

3.5秒 表面準備：兩片晶圓已平坦化、清潔，進行表面活化。銅墊相對SiO₂略微凹陷。 本圖凹陷高度大幅放大；沒有新增焊料或膠。

8.5秒 上片翻面：上片繞水平軸翻轉，讓兩個接合面相向。 角標及外接線跟著同一片晶圓；左右接點沒有鏡射交換。

13.5秒 精確對準：上片橫向移動，使兩對銅墊與相鄰介電區對準。 對位標記先重合，尚未接觸也未導通。

20秒 介電預接合：兩面靠近，在室溫由中央向外形成介電預接合。 綠色線代表已接合界面；銅墊仍有凹陷間隙，不能提前宣稱電性接通。

26秒 退火完成接點：退火強化介電接合，銅的凹陷間隙逐步閉合，形成固態金屬接合。 銅不熔化、不變成液滴；相鄰絕緣區仍隔開兩組接點。

29秒 連通路徑：沿第一對銅接點顯示上下導線的連通。 這是示意路徑，不是實際量測的電流或良率。

31.2秒 接合晶圓對移交：已接合的晶圓對整組離開，下一輪由新的一對進場。 完成接點不自行拆開。
