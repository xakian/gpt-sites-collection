# 功率封裝銅夾接合

批次 04／3，主題 1.0.0；共用規格 v1.0，範本 1.0.0，從 starter 複製且共用檔未修改。

執行 `node server.mjs`，開啟 http://127.0.0.1:4243/ 。無第三方執行依賴。發佈內容為 dist/。

model.js 保存科學狀態、時長與分鏡；materials.js 保存材料；drawing.js 與 svg.js 為圖形及布局；app.js 連接共用單一時鐘與控制。來源、簡化及關鍵幀在說明面板與 records/copper-clip/；驗收另存該目錄。

軟體測試 `?qa&motion=reduce` 僅測初始靜態模式，不代替實際系統或瀏覽器媒體偏好。
